// deadlockoptimization :: BALANCED preset :: video.txt values

// These are the keys the in-game Video menu reads and writes. install.ps1
// merges them into your existing video.txt and leaves your resolution,
// refresh rate, monitor index, fullscreen mode and deviceid untouched.
//
// Hardware notes (5700X + 9070 XT):
//   * gpu_level stays HIGH and texture mip bias stays 0. The 9070 XT has
//     16 GB of VRAM and is not the bottleneck; dropping textures gains nothing.
//   * cpu_level goes LOW. This is the engine's own CPU-side quality knob
//     (cloth, particle sim budget, misc). It is the single most useful
//     setting for a CPU-bound rig.
//   * Shadows OFF. Shadow cascades are extra draw-call passes = CPU time.
//   * Bloom, depth of field, motion blur OFF for visibility as much as fps.
//   * Anti-aliasing stays ON and render quality stays 100%: both are nearly
//     free on this GPU and lowering them would not raise your fps.
//   * r_low_latency 1 enables AMD Anti-Lag 2 inside the game (the convar
//     help text says so). Keep Anti-Lag enabled in Adrenalin too.
